## Key UX Patterns

### 1. Section Cards (Collapsible)
```
┌─────────────────────────────────────┐
│ Section Title        [+] [Edit] [▼] │ ← Header with actions
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ Section Content                 │ │ ← Collapsible content
│ │ • Item 1                        │ │
│ │ • Item 2                        │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

### 2. Inline Editing
```
BEFORE CLICK:                    AFTER CLICK:
┌──────────────────┐            ┌──────────────────┐
│ John Doe         │            │ [Input: John Doe]│
│ [Edit Button]    │     →      │ [Save] [Cancel]  │
└──────────────────┘            └──────────────────┘
```

### 3. Item Cards (Experience/Education)
```
┌─────────────────────────────────────────┐
│ ● Senior Software Engineer       [Edit] │ ← Hover shows actions
│   Tech Corp Inc.               [Delete] │
│   2020 - Present                        │
│                                         │
│   Led team of 5 developers...          │
└─────────────────────────────────────────┘
```

### 4. AI Generation Button
```
┌──────────────────────────────┐
│ [Rich Text Editor]           │
│                              │
│ Type your content here...    │
│                              │
├──────────────────────────────┤
│ [✨ Generate with AI]        │ ← Prominent AI button
└──────────────────────────────┘
```

### 5. Auto-Save Indicator
```
Top Right Corner:
┌────────────────────────────┐
│ ● Saving...                │ ← While saving
│ ✓ All changes saved        │ ← When complete
└────────────────────────────┘
```

## Responsive Breakpoints

### Desktop (1024px+)
- Full split-screen view
- Editor: 40% width
- Preview: 60% width

### Tablet (768px - 1023px)
- Stacked layout
- Editor on top
- Preview below
- Collapsible preview

### Mobile (< 768px)
- Single column
- Tabs to switch between editor and preview
- Touch-optimized controls

## Animation Details

### Hover Effects
- Cards lift slightly (translateY -2px)
- Shadow increases
- Duration: 200ms
- Easing: ease-out

### Section Expand/Collapse
- Smooth height transition
- Duration: 300ms
- Easing: ease-in-out

### Save Indicator
- Fade in/out
- Pulse effect while saving
- Success checkmark animation

## Accessibility Features

### Keyboard Navigation
```
Tab        → Move to next field
Shift+Tab  → Move to previous field
Enter      → Edit section
Escape     → Cancel editing
Space      → Toggle section
Arrow Keys → Navigate lists
```

### Screen Reader
- Proper ARIA labels
- Section headings (H2, H3)
- Button descriptions
- Form labels

## PDF Generation Flow

```
User Clicks "Download PDF"
         ↓
Backend receives request
         ↓
Puppeteer launches browser
         ↓
Navigates to /resume/preview/:id
         ↓
Page loads and signals ready
         ↓
Captures page as PDF (A4, high-res)
         ↓
Saves PDF to server
         ↓
Returns download URL
         ↓
User downloads file
```

## Performance Optimizations

### Debouncing
```
User types → Wait 1s → Save
User types → Wait 1s → (typing continues, timer resets)
User types → Wait 1s → Save (after 1s of no typing)
```

### Lazy Loading
```
Dashboard → Load resume list
Select resume → Load full data
Edit section → Load editor
Change tab → Load design settings
```

### Memoization
```
ResumePreview → Memo(props)
SectionCard → Memo(props)
EducationItem → Memo(props)
```
